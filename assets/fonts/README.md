# Bundled poster fonts

Noto Sans Devanagari and Noto Sans Gurmukhi, from the official Google Fonts repository, under the included SIL Open Font License 1.1 files. Downloaded 2026-10-12. Full variable fonts were losslessly converted from TTF to WOFF2 with fontTools; no glyphs were removed.

- https://github.com/google/fonts/tree/main/ofl/notosansdevanagari — source TTF Git blob `163f04bddc5a96fc523e4080466cac5c588f6594`
- https://github.com/google/fonts/tree/main/ofl/notosansgurmukhi — source TTF Git blob `49878eb913077538cc8973dcf4ad7c51f3e5fb22`

These fonts are served from this app and cached offline. No Google Fonts request is made by the app. Poster export waits for normal and bold fonts; failures are shown instead of silently exporting missing characters.

## Yatra One (fx display font)

Yatra One from https://github.com/google/fonts/tree/main/ofl/yatraone under SIL OFL 1.1 (`OFL-YatraOne.txt`). Subset with fontTools pyftsubset to Devanagari + Basic Latin, WOFF2. Downloaded 2026-10-13. Self-hosted; no Google Fonts request.
