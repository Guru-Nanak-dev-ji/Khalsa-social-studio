# Free KDN presentation layer

- Three.js 0.180.0: pinned from the official npm package; MIT; license preserved in vendor/THREE-LICENSE.txt. No runtime CDN.
- Existing Devanagari and Gurmukhi fonts are bundled under SIL OFL in assets/fonts.
- Existing user-supplied/generated artwork and welcome voices retain their existing provenance. This file does not assign them a new third-party license.
- No video API, payment SDK, paid credit, subscription, tracking pixel or new personal-data transmission is used by this layer.
- Intro films are real-time procedural animation, with an original SVG fallback. They are not generated MP4s or lip-sync video.
