# KDN AI WORKSPACE — DALJIT 01

**Status:** staging pilot; no autonomous external AI connected yet.

## Coordination
- Chief Coordinator: DALJIT 01 — approvals, priority, release.
- AI Coordinator: AKAAL SETU (KDN-AS-20261015-001) — task intake, evidence, QA, handover.
- Copilot: proposed code review/test lane; not automatically assigned.
- Grok: proposed research/3D lane; not automatically assigned.
- Human contributors: named only after acceptance.

## Working rules
1. GitHub Issues are the shared task list; one task per Issue.
2. Each Issue needs ID, owner or proposed owner, scope, acceptance criteria, evidence, next action, status.
3. AI agents must not claim work completed without commits, tests or evidence.
4. PRs into main require DALJIT 01 approval; no automatic production merge, deploy, DNS, deletion, payment or secrets exposure.
5. On completion or interruption, update the issue and add handover with what changed, what remains, blockers and successor.
6. Automated CI may check work, but external AI must be separately connected and authorized.
